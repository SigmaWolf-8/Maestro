## PHASE 2: Config & Tax Services (Day 4-5)

- [ ] **TASK-201:** Create `server/services/pricing-config-service.ts` (~180 lines)

  - Typed getters: getString, getInteger, getDecimal, getBoolean, getJson
  - getAllPublic() — returns only PUBLIC visibility configs
  - getAllByCategory() — for admin UI
  - getTaxRatesForProvince() — reads from pricing_config table
  - setValue/setValues with cache invalidation and updatedBy tracking
  - calculatePricing() — reads plan prices from DB + applies tax

- [ ] **TASK-202:** Create `server/services/tax-service.ts` (~100 lines)
  - calculateTax(subtotalCents, province, taxExempt?) → { taxLines, totalTaxCents }
  - All 13 Canadian provinces: GST-only (AB, NT, NU, YT), HST (ON, NB, NL, NS, PE), GST+PST (BC, SK, MB), GST+QST (QC)
  - getStripeTaxRateIds(province) — maps province to Stripe tax rate IDs from config
  - Reads ALL rates from PricingConfigService (never hardcoded)

- [ ] **TASK-203:** Create `server/services/stripe-product-service.ts` (~200 lines)
  - initializeAllProducts() — creates Stripe products + 4 prices each from DB
  - syncPlanPricing(planCode) — creates new Stripe prices, archives old (immutable in Stripe)
  - createCheckoutSession() — with Canadian tax rates, billing period, user count
  - migrateSubscriberPricing() — optional admin tool for renewals
  - Records all operations in stripe_sync table

- [ ] **TASK-204:** Create `scripts/dev/seed-subscriptions.ts` (~150 lines)
  - Seed pricing_config from PRICING_CONFIG_SEED (idempotent upsert)
  - Seed subscription_plans from PLAN_SEED_DEFAULTS (idempotent upsert)
  - Calculate yearly prices: Math.round(monthly × 12 × (1 - annualDiscountBps/10000))
  - Assign Professional plan to existing seed tenant
  - Create sample invoices and usage metrics

## PHASE 3: Core Services (Day 6-8)

- [ ] **TASK-301:** Create `server/services/ledger-witness-service.ts` (~120 lines)
  - Algorand primary (algosdk), Hedera fallback (@hashgraph/sdk)
  - witnessEvent() — SHA-256 hash of payload to Algorand app call, falls back to Hedera HCS
  - verifyWitness() — verify transaction on-chain
  - getTenantWitnessStatus() — provider, last witness, total events
  - initializeTenantLedger() — create Algorand account or Hedera topic for Enterprise+ tenants
  - Reads provider config from PricingConfigService

- [ ] **TASK-302:** Create `server/services/usage-tracking-service.ts` (~180 lines)
  - In-memory counters flushed to usage_metrics every 60s
  - trackApiCall, trackStorageChange, trackTernaryOperation, trackPhaseSyncEvent
  - trackLedgerWitnessEvent (algorand | hedera), trackFemtosecondEvent
  - getDailyUsage, getMonthlyUsage, getUsageTrend
  - checkLimits() — returns UsageLimitStatus[] with 80%/90%/100% thresholds
  - resetMonthlyCounters() — called on subscription period start

- [ ] **TASK-303:** Create `server/services/subscription-service.ts` (~250 lines)
  - getAllActivePlans() — reads from subscription_plans table
  - getActiveSubscription(tenantId) — with plan join
  - createSubscription() — locks in current pricing to tenant_subscriptions
  - upgradePlan / downgradePlan — prorated billing
  - cancelSubscription(immediate: boolean)
  - hasFeature() — reads features JSONB from plan
  - checkSecurityModeAccess() — hierarchy: zero < one < phi < phi-plus
  - getTenantEntitlement() — full entitlement summary
  - getSuggestedUpgrade() — recommends plan for missing feature

- [ ] **TASK-304:** Create `server/services/billing-service.ts` (~300 lines)
  - createStripeCustomer / getOrCreateStripeCustomer
  - createStripeSubscription — delegates to StripeProductService.createCheckoutSession
  - createTatSubscription — Algorand-based TAT transfer
  - createMixedSubscription — partial Stripe + partial TAT
  - generateMonthlyInvoice — with tax calculation via TaxService
  - calculateBilling — returns BillingCalculation with full breakdown
  - processPayment, handleStripeWebhook
  - processAllMonthlyBilling — batch automation
  - calculatePlenumnetCharges — reads rates from PricingConfigService

- [ ] **TASK-305:** Create `server/services/tenant-onboarding-service.ts` (~200 lines)
  - 7-step orchestration: tenant → admin → auth → subscription → PlenumNET → ledger → seed data
  - Uses existing storage.ts for tenant/user creation
  - Delegates billing to BillingService
  - Delegates ledger to LedgerWitnessService for Enterprise+ plans
  - Step tracking with OnboardingStep[] status

- [ ] **TASK-306:** Create `server/middleware/entitlement.ts` (~120 lines)
  - featureGuard(requiredFeature, requiredSecurityMode?) middleware factory
  - requireActiveSubscription() lightweight middleware
  - meetsSecurityLevel() helper
  - Attaches entitlement context to Express request
  - Returns 403 with upgrade suggestion, 429 for usage limits
  - CRITICAL: Does NOT apply to existing v3.1 routes
