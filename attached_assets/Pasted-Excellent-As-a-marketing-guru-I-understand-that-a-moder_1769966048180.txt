### **Core Philosophy for Each Theme:**
*   **Primary:** The dominant brand color. Used for key buttons, primary navigation, and important highlights.
*   **Secondary:** Complements the primary. Used for secondary actions, accents, and sub-sections.
*   **Accent:** A pop of color for alerts, success states, or interactive elements. Provides contrast.
*   **Neutrals:** A clean foundation of grays/off-whites for backgrounds, text, and cards.

### **Guru Implementation Notes for Your Replit App:**

1.  **CSS Variables is Key:** Implement these as CSS custom properties (e.g., `--primary-color`, `--bg-neutral`). This allows a single theme file to control the entire app's look.
2.  **Accessibility First:** Every combination must pass WCAG AA contrast ratios (4.5:1 for text). Use tools to check. The neutrals are chosen with this in mind.
3.  **Preview Switcher:** Build a sleek theme previewer in your settings panel. Let users see a dashboard mockup change in real-time.
4.  **Naming the Theme:** Use the evocative names I've provided (e.g., "Emerald Authority"). It sells the *feeling*, not just the colors.
5.  **Beyond Colors:** Remind clients that true branding extends to **font pairings** (a clean sans-serif like Inter or system-ui is safe) and **border-radius consistency** (e.g., 6px for buttons, 12px for cards).
